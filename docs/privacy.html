Privacy Policy

Last updated: 2026-05-25

1. Scope

This Privacy Policy describes how the Android application RunnerStats (the "App") handles data. RunnerStats is a private, single-user application installed only on the developer's own device. It is not published on any app store and is not distributed to third parties.

2. Data Controller

The data controller is the developer of the App, reachable at solotriples12@gmail.com.

3. Data the App Accesses

With the user's explicit authorization granted via Huawei Health Kit OAuth, the App reads the following categories of the user's own data from Huawei Health Kit:

  • Running and sport activity sessions (start time, duration, distance, calories, summaries).
  • Heart rate samples recorded during activities.
  • Location (GPS) samples recorded during activities.
  • Cadence, speed, distance and altitude samples.
  • Sport-related ability metrics (e.g. VO2max) when available.

The App does not access body fat, stress, sleep, blood glucose, blood pressure, SpO2, body temperature, cardiac health screening, pulmonary function, nutrition, reproductive, or any other health categories outside of running activities.

4. How Data Is Used

Data is used exclusively to compute and display statistics to the user on the same device, including but not limited to:

  • Rolling-window personal records (best 1K/5K/10K extracted from any longer run).
  • Cardiovascular efficiency trends over time.
  • Heart-rate-zone analysis per workout.
  • Per-workout charts of heart rate, pace and elevation.

5. Storage and Retention

All data is stored locally on the user's Android device in an encrypted-by-OS application database (Room/SQLite). Data is retained for as long as the App remains installed. Uninstalling the App removes the database and all data with it.

6. Data Sharing and Transfers

The App does not transmit data to any external server, backend, analytics platform, advertising network, or third party. The only network calls made by the App are:

  • The OAuth 2.0 authorization flow with Huawei Account Kit.
  • REST calls to Huawei Health Kit endpoints to retrieve the user's own data.

No telemetry, no crash reporting to external services, no usage analytics. The App contains no third-party SDKs other than the libraries required to interact with Huawei Health Kit and to render the user interface.

7. User Rights

The user is the sole owner of their data. The user may at any time:

  • Revoke Huawei Health Kit authorization from the Huawei Account settings.
  • Delete the App's local database by clearing the App's data in Android system settings.
  • Uninstall the App, which removes all data permanently from the device.

8. Children

The App is not intended for use by children. The developer does not knowingly collect data from minors.

9. Changes

Any future change to this policy will be reflected on this page with an updated date at the top.

10. Contact

Questions about this policy can be sent to solotriples12@gmail.com.
