About

RunnerStats is a personal-use Android application installed only on the developer's own device. It reads the developer's own running activity data from Huawei Health Kit and persists it locally for advanced statistical analysis (rolling personal records, cardiovascular efficiency trends, heart-rate zone analysis). It is not distributed via any app store.
